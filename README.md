# vx 4.x 提取工具

在本机浏览器中整理和导出微信聊天记录，不上传数据、不联网下载媒体。原始数据只读，解密在 `cache/` 副本中进行。

## 功能

- **账号选择**：通过文件夹弹窗选择微信文件路径，扫描账号。
- **密钥管理**：支持手动校验、内存提取及按账号保存复用，减少重复读取内存。
- **会话筛选**：联系人搜索、排序、多选，支持全部日期或自定义日期区间。
- **媒体导出**：图片、本地视频、接收文件，以及已定位语音转 WAV；图片可选择画质。
- **多格式导出**：HTML 离线查看、搜索和播放媒体；CSV 用于表格筛选；JSONL 保留结构化记录。可同时选择多种格式。
- **任务控制**：查看进度、取消导出、打开输出文件夹；标注媒体缺失、失败或未验证状态。

## 快速启动

准备 Windows 和 Python 3.12，在已激活的 Python 环境中进入项目目录，执行：

```bash
python -m pip install -r requirements.txt
python -m app.main
```

浏览器会自动打开 `http://127.0.0.1:8765/`；未自动打开时可手动访问。

## 使用方法

1. **选择路径和账号**：点击文件夹选择按钮，找到微信文件路径（WeChat Files），选到直接包含 `wxid_` 账号文件夹的那一层，再选择账号。
2. **准备密钥**：准备联系人和消息库密钥；已有可用密钥时直接复用，也可点击「验证已保存密钥」。导出语音还需准备媒体库密钥。
3. **生成会话列表**：完全退出微信，再点击「生成联系人列表」，勾选需要导出的会话。
4. **设置导出条件**：选择日期、媒体类型和输出格式，点击「开始提取」。
5. **查看结果**：完成后点击「打开输出文件夹」。结果按账号、任务和会话保存在 `output/`，HTML 可双击离线查看。

“微信文件路径（WeChat Files）”是通用称呼，例如 `D:\WeChat Files`；实际目录名以你的电脑为准。也可在 `config.yaml` 中配置，格式参考 `config.example.yaml`。

## 已知限制

- 仅支持 Windows 微信 4.x，不支持微信 3.x。
- 不合并 WAL，最近尚未写入主库的消息可能遗漏。
- 加密表情暂不能还原，部分语音可能无法定位；本地缺失的媒体无法补齐。
- 语音解码失败或缺少解码器时，仅保留 SILK 原始文件，不能在 HTML 中直接播放。
- 部分数据库存在 HMAC 页校验异常；特殊会话类型可能识别不准确。
- 接收文件导出和真实多开拦截仍缺少完整验证。
- 服务重启后无法继续查询原有导出任务状态，已完成的文件不受影响。
- 暂未提供免安装 Python 的独立程序。

## 风险告知

- **仅处理你有权访问的账号和数据。内存提取属于非官方操作，可能触发微信风控，不能保证账号零风险。**
- 提取前请自行断网、仅保留一个微信登录实例，并完成页面确认；媒体库提取需额外确认范围。
- 密钥、解密缓存和导出记录含敏感信息。不要上传 `keys/` 中的密钥、`cache/`、`output/` 或本机配置 `config.yaml`；`keys/.gitignore` 仅为可提交的占位规则文件。
